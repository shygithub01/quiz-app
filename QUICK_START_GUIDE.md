## Troubleshooting

### Landing page shows "No featured competition set":
- Go to Settings
- Select a scholarship competition
- Click "Set as Featured"

### Competition not showing on /competitions page:
- Check status (should be "active" or "upcoming")
- Check dates (past competitions show as "completed")
- Refresh page

### Can't create competition:
- Make sure you're signed in as admin
- Check OpenAI API key in .env.local
- Check browser console for errors
